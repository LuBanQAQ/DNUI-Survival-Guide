# DNUI 名词表

刚入学最先撞上的往往不是课程，而是一堆名词和缩写：素拓分、CA、培养方案、三方协议……这一页按主题做**速查**：每条只给最短的定义，细节都在链接的页面或官方文件里。

> [!TIP]
> 不用背，遇到看不懂的词回来查一下就行。本页所有说法都以学校与教务的最新文件为准。

## 学分与成绩

| 名词 | 含义 |
| --- | --- |
| **学分 / 学时** | 课程的计量单位。学校实行学分制收费，学费由课程学分学费与专业学费组成，**重修按学分交费** |
| **培养方案** | 你所在专业的课程与学分总表。选课要求、总学分、艺术类课程分都以它为准，在教务系统里查看 |
| **课程绩点** | 单门课的绩点：百分制课程为「成绩 ÷ 10 − 5」，**60 分起算**，低于 60 分记 0；等级制课程直接给定（优秀 4.5、良好 3.5、中等 2.5、及格 1.5） |
| **课程学分绩点** | 课程绩点 × 课程学分 |
| **平均学分绩点（GPA）** | 全部课程学分绩点之和 ÷ 总学分，保留两位小数，**不含毕业设计（论文）成绩**。算法与提分建议见[绩点、考试与复习](/study/gpa-and-exams) |
| **补考 / 重修** | 必修课与专业选修课不及格先补考，仍未取得学分须重修；**实践类课程与公共选修课没有补考**，直接重修。补考、重修获得的成绩在成绩单上会有标注 |
| **课程免听** | 「免听不免考」：经认定可以不上常规课堂与平时作业，但必须参加课程专项答辩，**答辩成绩就是最终成绩**。属各系细则，见[课程免听](/courses/course-exemption) |
| **过级激励** | 通过 CET-4/6 后可申请用四六级成绩替代或免修大学英语课程，见[英语课与四六级](/study/english) |

## 评优与素质学分

| 名词 | 含义 |
| --- | --- |
| **素质教育学分（素拓分）** | 素质教育项目考核学分 + 社会工作考核学分 − 日常行为考核学分；**本科 2 学分、专科 1.5 学分**，既是毕业门槛，也计入综合评优成绩 |
| **日常行为考核** | 迟到 0.2、旷课 0.3、通报批评 0.1、警告 0.2、严重警告 0.4、记过 0.6、留校察看 0.8（单位：学分/次） |
| **综合评优成绩** | 本学年学业成绩 × 80% + 学年素质教育考核成绩 × 20%，评优与评奖按它排序 |
| **操行考核** | 对学生品行与日常表现的考核成绩，奖学金要求达到「良好（含）以上」 |
| **创新创业实践学分** | 由 SOVO 创新实践、市级及以上学科竞赛、专业认证等累计而来，**上限 2 学分**，可认定为公共选修课学分（成绩记 90 分） |
| **竞赛类别（A / B / C 类）** | 学校对学科竞赛的分级认定，类别越高，同样的奖项能加的课程分越多 |
| **课程加分** | 学科竞赛获奖后加在某门课程上的分数。门槛是 **B 类省级三等奖及以上**（不含任何优秀奖），一学期只能申请一门课 |
| **奖学金** | 华天奖学金（最高荣誉）、东软睿新奖学金（一 / 二 / 三等）、国家奖学金、省政府奖学金、国家励志奖学金等，见[奖学金](/study/scholarships) |
| **学年评优** | 十佳大学生、三好学生、优秀学生干部、学习优胜奖等年度奖项，见[学年评优](/study/awards) |
| **晨读课 / 晚自习课** | 学校安排的晨读与晚自习，迟到、旷课同样计入日常行为扣分 |

素拓分与各类学分的完整规则见[素质教育学分与创新创业实践学分](/study/quality-credits)，竞赛加分标准见[竞赛类别与课程加分](/competition/levels)。

## 学籍与培养

| 名词 | 含义 |
| --- | --- |
| **学籍异动** | 休学（保留学籍）、复学、退学、降级、转专业、转学等学籍状态变更的统称，各有对应的申请与审批流程 |
| **转专业** | 大一结束时申请，只能选一个专业、只有一次机会，可能降级转入。见[转专业](/freshman/major-transfer) |
| **学业预警与帮扶** | 对学业出现困难的学生进行提醒与帮扶的机制，依据《学生学业预警与帮扶实施办法》 |
| **提前毕业** | 达到条件可申请提前毕业，依据《本科生提前毕业管理办法（试行）》 |
| **学位授予** | 本科毕业生获得学士学位的条件，依据《普通高等教育本科毕业生学士学位授予实施细则》 |
| **毕业设计（论文）** | 大四的毕设。**GPA 计算不含它的成绩**，另有独立的撰写规范与作假认定办法 |
| **小学期（实践学期）** | 暑假一个月左右的实践学期，报告类与实践类任务常安排在这个阶段，见[作业、实验与课程设计](/courses/assignments) |
| **大创项目** | 大学生创新创业训练计划项目，分国家级、省级、校级，可作为课程免听与评优的依据 |
| **微专业 / 创新实验班** | 在主修专业之外设置的培养项目，依据《微专业建设管理办法（试行）》与教务部的创新实验班安排 |
| **SOVO / 产业学院 / 定制培养** | 创新创业学院（SOVO）与产教融合相关的培养形式，入口见[教务部门户](https://jw.neusoft.edu.cn/)与 [SOVO 官网](https://sovo.neusoft.edu.cn/) |

> [!WARNING]
> 学籍类事项（休学、复学、退学、降级、转学）都要**交材料、走审批**，而且有时间窗口。表格、受理时间与条件以**教务部当年通知**为准，不要照着网上的说法操作。

## 账号与系统

| 名词 | 含义 |
| --- | --- |
| **学生 CA** | 学生统一身份认证入口，个人信息、绩点排名等在这里看：**企业微信 → 工作台 → 学生 CA** |
| **企业微信** | 校内通知与业务系统的总入口，成绩、排名、各类审批都从这里进 |
| **校园网认证账号** | 校园网上网用的账号，**实名上网、一人一号**，不要把账号借给别人 |
| **学生邮箱** | `@dnui.edu.cn` 后缀的教育网邮箱，也是找回各类账号的重要凭据 |
| **DNUI 综合服务平台** | 微信服务号 + 小程序的统一入口，负责账号开通、缴费、通行等服务 |
| **电子身份卡** | 手机上的动态二维码门禁凭证，不要截图外传 |
| **人脸识别** | 图书馆等场所的刷脸闸机，需要先在 DNUI 综合服务平台小程序里绑定人脸 |
| **校园卡 / 一卡通** | **DNUI 没有实体校园卡或一卡通**，食堂、洗澡等日常消费直接刷微信，见[校内消费与门禁](/campus/daily-services) |

常用系统的用途一览，完整入口见 [DNUI 常用网站导航](/campus/website-navigation)：

| 系统 | 用来做什么 |
| --- | --- |
| 教务系统 | 查课表、成绩、培养方案，申请成绩认定与过级激励 |
| 选课系统 | 选课与查看课程安排，见[选课与学分](/freshman/course-selection) |
| 东软智慧教育平台 | 校内课程学习与教学资源 |
| 超星学习通 | 课程资料与作业任务 |
| ITEST / 批改网 | 英语测试与英语写作练习 |
| 教评系统 | 学生评教（教学评价） |
| 素质教育管理系统 | 素质教育项目、学分与考核情况 |
| 实践学分管理系统 | 实践学分与课程加分申请 |
| 就业信息服务网 | 岗位、招聘会与宣讲信息 |

## 体育、升学与就业

| 名词 | 含义 |
| --- | --- |
| **校园跑 / AI 运动** | 体育课的课外锻炼打卡：用运动世界 App 跑步（**一学期 30 次**）、对着手机做指定动作并录视频。两者都有截止节点，**过期不补**，见[体育课、校园跑与体质测试](/study/pe-and-fitness) |
| **体测** | 《国家学生体质健康标准》测试，与优秀毕业生条件里的「国家体育锻炼标准」相关 |
| **体育单科线** | 学年评优给体育课单独设的门槛（三好学生 80 分、十佳大学生 75 分、优秀学生干部与学习优胜奖 70 分）；**奖学金反而明确不含体育课** |
| **秋招 / 春招 / 提前批** | 校园招聘的三个批次：秋招以 9–11 月为主，春招在次年 3–5 月，部分企业会提前开放提前批 |
| **三方协议** | 毕业生、学校与用人单位签订的就业协议（就业协议书），**签之前先看清违约条款**；办理流程以学校就业部门的通知为准 |
| **毕业生档案** | 毕业后的档案去向与转递，走[毕业生档案管理系统](https://archive.neusoft.edu.cn/) |
| **推免（保研）** | 「推荐优秀应届本科毕业生免试攻读研究生」的简称，资格、名额与条件按学校与学院当年文件执行 |
| **考研** | 全国硕士研究生招生考试（统考），报名与考试时间以[中国研究生招生信息网](https://yz.chsi.com.cn/)为准 |
